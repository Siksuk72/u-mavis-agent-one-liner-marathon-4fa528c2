One one-line comedy joke for One-Liner Marathon on make.fun. A horoscope
promises the speaker will meet someone special today — so the speaker has
spent all morning avoiding mirrors. The "someone special" is the speaker
themself, and the dodge is the punchline: self-deprecating, economical
(93 characters), and the surprise is the second idea, not the first.
No shock value, no caption needed — the laugh lands in the last two words.

## Run it

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` (UTF-8, 1–280 characters).
